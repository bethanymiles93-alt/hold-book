# Design direction

## Emotional brief

Hold should feel:

- held, not managed
- quiet, not empty
- warm, not childish
- hopeful, not falsely cheerful
- premium, not exclusive
- calm, not low-contrast
- simple, not vague

## Layout

- Generous purposeful space
- Clear single-column hierarchy
- One primary action
- Stable navigation
- Minimal visual noise
- No dense home dashboard

## Shape

Soft geometry may support the feeling of being held, but not every component should be rounded.

## Icon

The circle-being-held symbol should remain separate from the wordmark.

Potential uses:

- app icon
- active Hold indicator
- completion state
- loading state
- brand mark

## Motion

- Slow, subtle and functional
- Never block progress
- Respect reduced motion
- No bouncing, confetti or gamified celebration
