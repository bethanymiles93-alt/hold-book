# Low-capacity design

## Premise

Hold must work when attention, working memory, initiation capacity and emotional tolerance are sharply reduced.

## Sources of avoidable load

- Too many choices
- Long onboarding
- Requiring a complete explanation
- Ambiguous buttons
- Dense text
- Tiny controls
- Unclear consequences
- Pressure to specify when recovery will happen
- Repeated requests for data

## Recommendations

- One primary action per screen
- Progressive disclosure
- Useful editable defaults
- Save unfinished drafts
- Show recipient names before sending
- Use short, plain language
- Permit “I do not know” and no end date
- Make back, edit and cancel obvious
- Avoid time limits
- Preserve context after interruption
- Keep the essential send flow very short

## Proposed MVP send flow

1. Tap **Create a Hold**
2. Choose people or a saved circle
3. Choose an intent
4. Review a short draft
5. Share using the native share sheet
6. Completion: **Ready. Then rest.**
