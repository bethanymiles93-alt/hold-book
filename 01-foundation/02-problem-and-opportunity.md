# Problem and opportunity

## The underlying problem

People can care deeply while being temporarily unable to reply, explain, reassure or reconnect. Others see the silence but cannot see the lost capacity behind it.

Silence therefore acquires a meaning:

- “They do not care.”
- “I have done something wrong.”
- “They are unreliable.”
- “I should stop trying.”

The person who has gone quiet may simultaneously think:

- “It has been too long.”
- “I need to explain everything properly.”
- “They will be angry.”
- “I have already ruined it.”
- “I cannot face the reply.”

## Relationship-erosion loop

1. Reduced capacity
2. Delayed response
3. Shame or guilt
4. Avoidance
5. Greater delay
6. Misinterpretation
7. Reduced trust
8. Harder return

## Opportunity

Hold can create value at three moments.

### Before
Help the user tell selected people that capacity is low.

### During
Reduce uncertainty without creating another task.

### After
Help the user return without writing a perfect explanation or apology.

## Core hypothesis

A small, timely message can preserve more trust than a longer explanation sent much later.

## Validation questions

- What prevents users from sending even a prepared message?
- What reassurance do recipients need?
- When does a message feel too vague, clinical or dramatic?
- Does an expected return date help or create pressure?
- Does sending a Hold reduce later guilt and avoidance?
